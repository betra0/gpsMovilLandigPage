# GPSMovil Landing Page

## Descripción

Esta es una **landing page** para **GPS Móvil** — una plataforma de monitoreo y gestión de ubicación por GPS para vehículos y flotas.

## Qué ofrece

- Seguimiento en tiempo real de vehículos y activos.  
- Gestión de rutas, alertas y reportes. 
- Control y optimización de operaciones. 

## Objetivo

Brindar información clara y directa sobre los servicios de seguimiento GPS y facilitar el acceso a la plataforma.
